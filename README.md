# Dokumentacja projektu Translator

Niniejsze repozytorium zawiera dokumentację do projektu Translator API & GUI.

---

## Link do dokumentacji

https://kruk24.github.io/translator/

## Jak uruchomić dokumentację lokalnie

### 1. Zainstaluj wymagane pakiety

Upewnij się, że masz zainstalowanego Pythona (>=3.8) oraz `pip`.

Zainstaluj MkDocs i motyw:

```bash
pip install mkdocs mkdocs-material
```

### 2. Uruchom serwer lokalny

Z katalogu głównego repozytorium uruchom:

```
mkdocs serve
```

Po chwili dokumentacja będzie dostępna pod adresem:

http://127.0.0.1:8000/
